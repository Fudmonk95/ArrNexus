ArrNexus v11

A personal Zurg-first control plane for this server.

What ArrNexus is now

ArrNexus no longer tries to be the low-level media filesystem. Zurg owns that job. ArrNexus concentrates on health, request visibility, Arr orchestration, list import, Jellyfin collection automation and music discovery.

This branch is intentionally built for one server rather than trying to cover every possible media stack. The source can still be forked and changed if somebody wants to take it in a different direction.
