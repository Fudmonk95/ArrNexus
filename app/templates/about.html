What ArrNexus is now

Zurg owns the source library and acquisition/storage layer. ArrNexus concentrates on request visibility, Arr orchestration, missing-media supervision, queue recovery, list import, Jellyfin collection automation and music discovery.

The Missing Media Orchestrator can either coexist with NeutArr or own the controlled missing-search cadence itself. Queue Janitor rescues safe ID-matched imports, cleans confirmed bad releases, defers stalls to Swaparr by default and stops at a hard retry limit instead of looping forever.

This build is intentionally designed around one server rather than every possible media stack. The source remains available to fork and adapt.
