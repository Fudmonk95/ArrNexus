# Changelog

## 4.0.0

- Fixed Discover shelf template crash / HTTP 500.
- Added source-isolated Music Hub providers and Deezer discovery.
- Added optional app-only Spotify catalogue search (no personal user OAuth).
- Isolated Lidarr failures from music discovery browsing.
- Added TV pack modes: Any / Full Series / Season Packs / Episodes.
- Added TV release-name pack classification and expected-season coverage.
- Added Real-Debrid instant-cache badges/filtering for torrent results.
- Added smart full-show acquisition with complete-pack preference and season-pack fallback.
- Added Sonarr season coverage visualizer and `Get missing seasons only` acquisition.
- Added pack-aware release size ceilings and scoring.
- Added Problem Centre with namespace, service, broken-link, failed-job and error-log summaries.
- Added more defensive Discover error isolation/logging.
- Retained v3 Portainer-first configuration, diagnostics, notifications, backups, profiles/themes, PWA, timelines, routing and import workflows.
